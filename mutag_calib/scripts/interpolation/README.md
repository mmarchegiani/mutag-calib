# Interpolation of scale factors between working points

## Example for data format

Script make_clib_example.py, filled with example (or "fake") scale factors, generates example correctionlib json file "Xbb_SF_2020.json".

3 pT bins [[300, 350], [350, 425], [425, inf]] and 5 working points [0.5, 0.6, 0.7, 0.8, 0.9] are used.

Inside the json file you can't find the scale factors and variations, but only the slope and intercept parametes used in the interpolation.

### How to evaluate scale factor and variation

Python code shows expected behavior

```python
import numpy as np
import correctionlib

cset = correctionlib.CorrectionSet.from_file("Xbb_SF_2020.json")
corr = cset["Xbb_SF"]

corr.evaluate(0.7, 350.0, "nom") #0.985
corr.evaluate(0.8, 350.0, "nom") #0.983
corr.evaluate(0.75, 350.0, "nom") #0.984 from interpolation

corr.evaluate(0.7, 350.0, "up") #1.032
corr.evaluate(0.8, 350.0, "up") #1.033
corr.evaluate(0.75, 350.0, "up") #1.0325 from interpolation

corr.evaluate(0.7, 350.0, "down") #0.938
corr.evaluate(0.8, 350.0, "down") #0.9329999999999999
corr.evaluate(0.75, 350.0, "down") #0.9355 from interpolation

corr.evaluate(0.7, np.array([310., 375., 500.]), "nom")  #array([0.995, 0.985, 0.975])
corr.evaluate(0.6, np.array([310., 375., 500.]), "nom")  #array([0.997, 0.987, 0.977])
corr.evaluate(0.66, np.array([310., 375., 500.]), "nom")  #array([0.9958, 0.9858, 0.9758]) from interpolation
```

- Inputs are `WP`, `pt` (GeV) and `systematic` (`nom`, `up`, `down`). `WP` and `pt` must be floats, integers are rejected.
- Structure: binning on WP, then binning on pT, then the `systematic` category, then a formula
  `[0]+[1]*x` with `x = WP`: the straight line between the SF or up/down variation at the two neighbouring measured WPs.

- A WP outside the given range raises an error.
- pT outside the bins is clamped: below the first bin edge the first bin is used, above the last bin edge the last bin is used (no errors raised)

## Xbb tagger scale factors, Run 2 and Run 3

Files in the clib json format are generated by file make_clib_data.py. It contains scale factors derived for HIG-26-013.

Output files are named `Xbb_SF_<era>.json` (example `Xbb_SF_2022_preEE.json`).

The expected behavior is the same as for the example file.

- Working points for scale factor derivation: 0.5, 0.6, 0.7, 0.8, 0.9, 0.99.
- Up / down variations: `SF + sigma_tot` and `SF - sigma_tot`, as measured with the mu-tagged method.
- pT bins (GeV, AK8 jet pT):
  - Run 2: [250, 300], [300, 400], [400, 450], [450, inf]
  - 2022 to 2025: [250, 300], [300, 350], [350, 425], [425, inf]
- A WP outside [0.5, 0.99] raises an error.
- pT outside the bins is clamped: below 250 GeV the first bin is used, above the last bin edge (13000 GeV) the last bin is used.
